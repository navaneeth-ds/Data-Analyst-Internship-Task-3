# Data-Analyst-Internship-Task-3
# 🗄️ SQL for Data Analysis

## 📌 Task Overview

This project is part of the **Data Analyst Internship – Task 3**.

The objective of this task is to use **SQL** to extract, manipulate, and analyze structured e-commerce data using **MySQL Workbench**.

## 🎯 Objectives

- Retrieve data using SQL queries.
- Filter data using `WHERE`.
- Sort and group data using `ORDER BY` and `GROUP BY`.
- Perform calculations using aggregate functions such as `SUM()` and `AVG()`.
- Use `INNER JOIN`, `LEFT JOIN`, and `RIGHT JOIN`.
- Use subqueries for analysis.
- Create a SQL view for reporting.
- Create an index for query optimization.

## 🛠️ Tools Used

- 🐬 MySQL
- 🖥️ MySQL Workbench
- 📄 SQL

## 🗃️ Dataset

A small **e-commerce database** was created specifically for this task.

The database contains three tables:

- `customers`
- `products`
- `orders`

The complete database creation and sample data are included in the `Task3.sql` file.

## 🔍 SQL Analysis Performed

The following SQL concepts were implemented:

- `SELECT`
- `WHERE`
- `ORDER BY`
- `GROUP BY`
- `SUM()`
- `AVG()`
- `INNER JOIN`
- `LEFT JOIN`
- `RIGHT JOIN`
- Subqueries
- Views
- Indexes

## 💡 Key Results

- 💰 Total sales were calculated using `SUM()`.
- 📊 Sales were analyzed by product category.
- 🏷️ Products priced above ₹10,000 were identified.
- 📈 The average product price was calculated.
- 🔎 A subquery was used to find products priced above the average.
- 🔗 Multiple JOIN operations were performed to combine customer, product, and order information.
- 📋 A view named `category_revenue` was created for category-level revenue analysis.
- ⚡ An index was created on `orders.customer_id` for query optimization.
